$ npm install @elite-club/agent-kit

Usage

Drop it into any interface that needs a live "agent is working" indicator.

React JS 
import { AgentOrb } from "@elite-club/agent-kit"

export default function App() {
  return (
    <AgentOrb state="thinking" size={48} speed={1.2} />
  );
}
import { createAgentOrb } from "@elite-club/agent-kit"

const orb = createAgentOrb("#orb-root", {
  state: "thinking",
  size: 48,
  speed: 1.2
});

orb.mount();

Props Reference (All optional)
